# Implications for the SPAR proposal (agent report, condensed; verified numbers)

A. Established: (A1) a frozen OOD CoT-Control score can be moved by benign SFT on a ~9B model (Q5 12.1 % vs base 0.3 %, p=4.8e-11; continuous 0.28 -> 0.51); (A2) multi-constraint examples beat single-constraint in-domain on both models (Qwen3.5 T3/S1 1.97, Qwen3-8B McNemar p=.004; magnitude does not replicate); (A3) held-out combinations of trained rules are not a hard test (no gap anywhere); (A4) transfer follows the granularity of the EDIT: whole-trace register switches transfer, sentence-level partially via twins, per-token and semantic not at all; (A5) a non-zero base floor is not a prerequisite; (A6) OOD accuracy unchanged by the manipulation; (A7) paired-eval infrastructure and saved checkpoints.
B. Not established (corrected wording): B1 "generalises to unseen conditions" -> robustness to template change for trained/mirrored constraints plus one genuinely new whole-trace format (JSON); B2 JSON was not learned from the six constraints: base already writes {"reasoning": ...} in its ANSWER field on 37/40 json prompts (verified), SFT relocated a known format into the reasoning stage; JSON passes ~8x shorter, 27 % accurate vs ~60 %; B3 "constraint maxing" untested (M5/Q4/P2 unevaluated; Q5 < T3 on singles p=.035; k confounded with number of combinations); B4 monotone-in-k not supported; B5 "overfits with more training" -> a T3-specific, JSON-dominated step-60 transient, not replicated on Qwen3.5; B6 S1 "gets worse" is one constraint (end_checker) on Qwen3.5; B7 tax pattern = scorer artefact + question mix; B8 "Qwen3.5 exceptionally bad" not supported (matched T3 equal or better); B9 continuous does not strengthen multi > single; B10 metric artefacts (suppression denominator, zero-tolerance case grader, ignore_question abstention).
C. Design: k=3 from >=12 distinct combinations, no supersets of held-out combos; match supervised tokens AND trace-length distribution across arms, length check on every edit (0.8-1.2x), report generation length as an outcome; checkpoint rule: never select on the OOD score, pick earliest in-domain plateau within a length band, apply identically to all arms, report trajectory; model gate on base trace length (<2k median) and no abstention; metrics per family with twins excluded, continuous beside binary, notation-aware case grading, accuracy per source with boxed fallback, empty-think as its own outcome; H1 by family; H3: distal -> proximal = 0 observed; primary contrast needs a monitor a register switch can evade; power: seed SD unmeasured, 6.2 pp within-arm checkpoint swing is the only proxy, 8-pair sign test needs all pairs to agree; run a 3-seed pilot first; pre-register the twin audit, combinations, exposure unit, checkpoint rule, grading conventions.
D. Risks: primary contrast may be null (distal -> proximal 0); JSON-only novel transfer and it is relocation; trace-length collapse entangled with every result (0 passes > 4k tokens); one seed everywhere; model specificity; accuracy cost in transferring arms; twin leakage in held-out families.
