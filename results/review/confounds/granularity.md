# Confound: granularity of the constraint (agent report)

Tier structure holds: global (json +0.55/+0.64, lowercase +0.25 bin, uppercase +0.18/+0.71 at Q5 k=1) > sentence (end_of_sentence +0.17/+0.47, repeat +0.03/+0.33) > token (meow, word suppression: zero binary, continuous slightly NEGATIVE under S1/T3) > semantic (ignore_question 0 everywhere). Same ordering inside k=3 and k=6 prompts (Q5: lowercase +0.40/+0.68 bin at k3/k6, uppercase +0.34/+0.42, eos +0.24/+0.31).
Exception explained: alternating_case is global in scope but per-character in execution; Q5 substitutes a trained register instead (16/40 traces ALL CAPS, 2/40 all lowercase, 0 alternating), which scores LOWER under the per-character grader -> flat 0.14. T3 shows the same at 2-3/40. => state the hypothesis as granularity of the EDIT, not the scope.
Twin grouping vs granularity: eta^2 comparison flips by arm/level (granularity wins for T3-60 and Q5 at k=1; twin wins for S1-final, T3-final and at k=3). Decisive qualitative facts: json (removed from training) is the largest binary mover; repeat_sentences gain is head-only (36/40 start with the target, 1/40 end), i.e. not via the end_checker twin; exact-twin end_of_sentence gives S1 +0.57 continuous but +0.03 binary. Twin status is a real secondary boost and the only thing S1-final transfers.
Implication: transfer is best predicted by the kind of edit the mode demands: whole-trace register/template switches the model already owns transfer even untrained; per-sentence edits partially and mainly with a trained twin; per-token/per-character edits and semantic control do not transfer and can be slightly hurt. Use binary for lowercase (continuous at ceiling) and both metrics for token modes.
Confidence: moderate-high on the tier ordering and the alternating_case mechanism; moderate on granularity > twin.
