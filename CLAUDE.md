# Notes for agents working in this repository

- **Uploading a model to Hugging Face:** follow [`HF_UPLOADS.md`](HF_UPLOADS.md). Every upload must include a
  `README.md` in the model folder with a results summary and figures: in-domain compliance, generalisation to held-out
  rules, how concentrated the gain is in a few rules, and answer accuracy. An upload without it is not finished.
